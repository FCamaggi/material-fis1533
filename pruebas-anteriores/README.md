# Pruebas anteriores de FIS1533

Todas las interrogaciones (I1, I2, I3), exámenes, controles y tareas que reunimos, **una sola copia de cada archivo**. Vienen del Drive Solidaridad, del material de 2026-1, de las pautas de cada semestre y de las carpetas compartidas en el chat del curso 2026. Créditos en [CREDITOS.md](../CREDITOS.md).

**Cómo se llaman los archivos:** `<Tipo> <Año>-<Semestre> (<variante>)`. Sin variante, es el enunciado (a veces con solución incluida). Variantes: `pauta`, `solución`, `enunciado`, `alternativas`, `pauta P1` (solo ese problema), `pauta manuscrita`, `otra versión` (el mismo semestre con otro contenido). La transcripción de cada PDF está en `markdown/` con el mismo nombre; las de mejor calidad (LaTeX completo) son las pautas oficiales desde 2024-2.
